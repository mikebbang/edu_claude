# 업무 설계서

## 1. 자동화할 업무
- 업무명: 불량 wafer의 lot·wafer·value를 받아 설비 이력으로 스텝 내 오더별 유닛 조합을 대조해 불량 조합을 찾고, 해당 유닛의 FDC 데이터를 비교해 유의차와 원인 가설을 정리해 보고

## 2. 입력 자료

| 자료 이름 | 형식 | 주요 내용 |
|---|---|---|
| 불량 wafer 측정값 | txt (엑셀에서 복사해 붙여넣은 탭 구분 값) | 측정된 전체 wafer의 lot, wafer, value(불량률 %) |
| 설비 진행 이력 (DB 추출) | csv | lot, wafer, step, order, unit, 진행 시각 |
| FDC 요약 데이터 (DB 추출) | csv | lot, wafer, step, unit, FDC 파라미터명, 요약값(평균·최대 등), 진행 시각 |

## 3. 결과물

- 결과물 형태: 불량 원인 분석 결과를 위에서 아래로 읽는 보고서 (차트 중심, 설명 문장 최소화, standalone HTML 1장)
- 구성:
  - 분석 요약: 입력 wafer 수, 이력 매칭률, 전체 평균 불량률, 조합이 좁혀지는 과정 (전체 조합 → 이탈 → 불량 조합)
  - 조합 funnel 차트: X = 조합 wafer 수, Y = 평균 불량률, 우연 범위 띠, 불량 조합 표시
  - 불량 조합별 상세: 스텝 흐름도 (order × unit, 불량 경로 표시), wafer 분포, order별 unit 평균과 신뢰구간, 시간 추이
  - FDC 유의차: 불량 조합 wafer와 같은 unit을 지난 나머지 wafer의 파라미터별 비교, 유의차 순위, 차이가 큰 파라미터의 분포와 시간 추이
  - 원인 가설과 확인 요청 사항: 유의차를 근거로 한 원인 가설 (확정 표현 없이), 엔지니어가 확인할 항목

## 4. 세부 업무 단계

| 단계 | Task | 실행 주체 |
|---|---|---|
| 1 | lot·wafer·value 붙여넣기와 good/bad 구분 입력 | 사람 |
| 2 | 입력값 정리(형식 확인, 중복·결측 제거)와 설비 진행 이력 조회·lot·wafer 기준 결합 | 코드 |
| 3 | 스텝별 order·unit 조합 생성과 bad wafer가 유의하게 몰린 불량 조합 판정 | 코드 |
| 4 | 불량 조합 unit의 FDC 데이터 조회와 파라미터별 유의차 계산(bad 경로 wafer vs 같은 unit의 나머지 wafer) | 코드 |
| 5 | 유의차가 큰 FDC 파라미터의 의미 해석과 원인 가설 도출 | AI |
| 6 | 차트와 원인 가설·확인 항목을 정리한 분석 보고서 작성 | AI |
| 7 | 원인 확정과 조치 결정(unit 점검, 경로 회피) | 사람 |
