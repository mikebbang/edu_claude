# 분석 결과 작성 공통 규칙

모든 Sub Agent가 결과물(해석, 보고서, 검토 의견)을 작성할 때 지킨다.

- 수치는 입력 파일(`output/analysis.json`, `output/fdc/조합ID.json`)에 있는 값만 쓰고, 새로 만들지 않는다.
- 원인은 가설로만 쓴다. "가능성", "추정"으로 표현하고 확정 표현을 쓰지 않는다.
- step, order, unit, 파라미터명은 입력 자료의 표기를 그대로 쓴다.
- 원인 확정과 조치 결정은 하지 않는다. (사람 Task)
- 실습 데이터는 가상 데이터이며, 실제 회사명·담당자·사내 데이터를 쓰지 않는다.
