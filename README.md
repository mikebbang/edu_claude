# 공정 조합 퍼널

한 스텝 안에서 오더별 유닛 조합을 거친 웨이퍼의 평균 불량률을 funnel plot으로 보고, 우연이나 다른 유닛 탓으로 설명되는 조합을 걸러 진짜 불량 조합만 남기는 분석 화면입니다. 데이터는 mock입니다.

## 실제 데이터 분석

`notebooks/real_data_funnel.ipynb`는 저장소 최상위(`unit_combi` 폴더)의 `raw.csv` 하나만 읽어 같은 판정을 돌립니다. 실제 데이터를 `raw.csv`라는 이름으로 두고 위에서부터 실행하면 됩니다. 결과는 한 장 funnel → 혐의 대상 표(초과 bad · 확실도) → Order 수별 판정(검증용) → 1위 자세히 → 경계선 비교 순서로 나오고, 데이터 점검 · 계산값 · 판정 방식 설명은 노트북 맨 아래 부록에 있습니다.

- 저장소에는 가상 demo 데이터 `demo_raw.csv`(STEP 20개, 웨이퍼 1,000장 중 good_bad N 30장, 불량 2개, `step_seq`는 `ex100100_1`처럼 STEP 번호 + `_Order 번호`)만 있습니다. demo로 확인하려면 `raw.csv`로 복사해서 실행합니다.
- `raw.csv`는 저장소에 없고 `.gitignore`로도 빠지므로, 새 버전을 ZIP으로 받아 덮어 풀어도 실제 데이터가 바뀌지 않고 커밋될 일도 없습니다.

- 필요한 컬럼: `analysis_date, job_id, root_lot_id, lot_id, wafer_id, tkin_time, line_id, part_id, step_seq, step_desc, eqp_id, chamber_id, ppid, y_value, good_bad, step_ord` (`raw.csv` 하나에 job 하나. `analysis_date, job_id, lot_id, ppid`는 읽지 않음)
- `y_value`는 모든 웨이퍼에 있어야 합니다. `good_bad`는 `G` · `B` · `N`이고, N인 웨이퍼는 계산에서 빼고 차트(4절 Value 분포의 빈 원, 부록 A)에만 표시합니다.
- 웨이퍼 = `root_lot_id` + `wafer_id`, 유닛 = `eqp_id-chamber_id`, Value = `y_value`
- STEP = `step_seq`에서 끝의 `_번호`를 뗀 값, Order = 그 번호. 예: `ex100000_1` ~ `ex100000_6` → STEP `ex100000` 안의 Order 1~6. 끝 번호가 없는 `step_seq`는 그대로 STEP으로 보고 `step_ord`를 Order로 씁니다. 여러 part를 함께 분석합니다.
- Value가 한쪽으로 길게 치우치면 순위 점수(순위를 정규분포 점수로 옮긴 값)로 분석합니다.
- part가 둘 이상이면 part마다 Value · bad를 맞춥니다(`PART_ADJUST`). 맞추지 않으면 좁게 퍼진 part의 차이는 작게, 넓게 퍼진 part의 차이는 크게 보여 한쪽 part의 불량이 묻힐 수 있습니다.
  - Value: 순위 점수로 분석하면 part마다 순위 점수를 매긴 뒤 모아서 다시 순위 점수로 바꿔 평균 · 퍼짐 · 모양을 같게 합니다. 순위로 바꾸지 않으면 part마다 평균과 표준편차를 맞춥니다.
  - bad: 조합의 bad 장수를 part 구성으로 기대되는 장수와 비교하고, 흩어짐도 part마다 p(1−p)로 잽니다.
  - 조합은 자기 part의 평균과 비교되므로 z의 √(1 − 조합 웨이퍼 수 ÷ 전체 웨이퍼 수)도 part별로 계산합니다.
  - 웨이퍼가 `PART_MIN`(20)장보다 적은 part는 하나로 묶습니다. part가 하나이면 결과는 이전과 같습니다. `PART_ADJUST = 'auto'`면 part 간 평균 차이가 뚜렷할 때만 맞춥니다.
  - part를 맞추지 않은 순위 점수 분석일 때만 6절 차트의 세로 눈금을 실제 입력 Value로 적습니다.
- 판정 기준은 하나입니다. 웨이퍼(`root_lot_id` + `wafer_id`) 한 장을 하나의 표본으로 보고, 조합마다 나머지 웨이퍼와 비교한 Value 차이의 z와 bad 비율(`good_bad`) 차이의 z를 구해 결합 z = (z_Value + z_bad) ÷ √(2 + 2r)로 합친 뒤 기준 z와 비교합니다. 기준 z는 5%를 Order 수로 나누고 Order 수마다 조합 수만큼 다시 나눈 값이라, 차트 전체에서 우연히 하나라도 넘을 확률이 5%입니다. Order 1개 조합의 z가 이론(퍼짐 1)보다 넓게 퍼져 있으면(같은 랏 웨이퍼가 함께 움직이는 등) 그 배수만큼 기준을 넓힙니다(`SPREAD_ADJUST`). r은 두 z가 우연히 같이 움직이는 정도라 같은 정보를 두 번 세지 않게 합니다. bad 비율 z는 정확한 이항 꼬리확률로 맞춥니다.
- 전체 평균에는 조합의 웨이퍼도 들어 있어서, 그대로 비교하면 큰 조합일수록 차이가 작게 나옵니다. 그래서 z를 √(1 − 조합 웨이퍼 수 ÷ 전체 웨이퍼 수)로 나눕니다(예: 전체 1,130장 중 400장인 조합은 1.24배). funnel 기준선도 같은 비율로 좁아집니다.
- 대표 불량 대상은 **초과 bad 웨이퍼 수**(bad 장수 − 기대 bad 장수), 즉 고치면 줄어드는 bad 웨이퍼가 많은 순으로 랭킹합니다. 기대 bad 장수는 웨이퍼 × 전체 bad 비율이고, part별로 맞췄으면 판정과 같게 웨이퍼마다 자기 part의 평소 bad 비율을 더한 값입니다. 이때 혐의 대상 표에 'part 구성으로 기대' 열이 함께 나옵니다.
- 조합에 필요한 최소 웨이퍼 수는 `MIN_N`(기본 4, lot 하나 단위로 넣어도 조합이 생기도록)입니다. 웨이퍼가 많은 데이터에서는 작은 조합이 크게 늘어 계산이 오래 걸리고, 웨이퍼가 적은 조합은 기준선을 넘기 어려우니 10~20으로 올려도 됩니다.
- 조합에 묶을 최대 Order 수는 `MAX_DEPTH`(기본 5)로 바꿉니다. 늘리면 계산이 늘고, 5%를 더 많은 Order 수로 나누므로 Order 1개 조합까지 모든 기준 z가 조금씩 올라갑니다. Order 3개 이상 조합은 Order 하나를 뺀 조합 중 하나라도 z 1.96을 넘을 때만 계산합니다(계산량 때문). 기준 z는 계산하지 않은 조합까지 센 가능한 조합 수로 정하므로 우연히 넘을 확률은 늘지 않고, 3절 판정 줄에 계산한 수와 가능한 수를 함께 적습니다.
- 6절은 같은 조합에 경계선 두 가지를 따로 그려 비교합니다. Bonferroni는 실제 평균 위에 그린 차트와 3절처럼 띠 하나로 그린 차트 두 장입니다. 둘 다 μ ± 배수 × σ/√N이고 배수를 정하는 M만 다릅니다: 지금 판정의 Bonferroni(M = 같은 Order 수의 전체 조합 수)와 √(2 ln M_N)(M_N = 웨이퍼 수가 N ÷ 1.25 ~ N × 1.25인 점 수(`MEMO_WINDOW`), 주변에 점이 하나뿐인 N은 경계 없음). 레퍼런스처럼 같은 N의 점만 세면 큰 N에서 M_N이 2~5로 작아 경계가 지나치게 좁아지고 N에 따라 민감도가 들쭉날쭉해서, 비슷한 N의 점을 함께 셉니다(`MEMO_WINDOW = None`이면 레퍼런스 그대로). σ/√N은 N장씩 무작위로 뽑은 평균들의 표준편차와 같은 값을 식으로 구하고, 실제 조합이 퍼진 만큼 넓힙니다(Bonferroni는 퍼짐 배수 하나, √(2 ln M_N)은 N 주변에 찍힌 모든 점으로 잰 N별 퍼짐 s(N)). 비교를 위해 세 차트 모두 Value z만 씁니다. 6절 끝 셀은 part_id마다 그 part의 웨이퍼만으로 조합을 다시 계산해 같은 차트를 그리고(`PART_KINDS`로 차트 종류, `PART_LIST`로 part를 고름), part 안에서 경계 밖인 대상이 합친 판정에서도 밖인지 대조합니다. 한 part에서만 나쁜 유닛을 다른 part도 쓰면 합친 판정에서는 옅어지므로(희석) 이 표로 확인합니다.
- 웨이퍼가 거의 같은 혐의 대상(예: 하위 스텝 여러 개를 같은 챔버에서 진행)은 데이터로 구분할 수 없어 랭킹에서 한 줄로 묶습니다.
- 한글 글꼴은 `notebooks/fonts`의 나눔고딕을 자동으로 씁니다. 노트북을 다른 곳으로 옮길 때는 이 폴더도 노트북 옆에 함께 두세요.

## 판정 기준

1. 조합 크기(오더 수)별 탐색 공간 크기로 Bonferroni 보정한 envelope를 넘어야 합니다.
2. 오더 하나를 뺀 경로의 나머지 웨이퍼와 비교해도(Welch t) 같은 보정 기준 z를 넘어야 합니다 (아니면 상속). 기준을 넘은 조합은 평균이 높게 뽑힌 쪽이라, 예전 규칙인 고정 유의수준(p < 0.001)으로는 진짜 불량의 효과를 물려받은 조합이 자주 통과했습니다.
3. 더 작은 불량 조합의 웨이퍼를 빼도 여전히 높아야 합니다 (아니면 하위 기인).
